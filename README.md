# Blackbox
Blackbox is a Python package designed to provide an easy-to-use interface for evaluating computationally expensive engineering and scientific problems. It simplifies the process of generating high-fidelity simulation data by abstracting problem setup, simulation execution, and data handling. The package enables efficient data generation for downstream applications such as surrogate modeling, optimization, uncertainty quantification, sensitivity analysis, and design exploration.

## Documentation
Please see the [documentation](https://computationaldesignlab.github.io/blackbox/) for installation details and how to use various problems implemented within Blackbox.
