__init__(env_name, lb=-1.0, ub=1.0, num_rollouts=3, seed=None)[source]

Class for setting up MuJoCo environment and run the simulation

Parameters:

  • env_name (str) – name of the mujoco environment, must be: ‘Swimmer-v5’, ‘HalfCheetah-v5’, ‘Hopper-v5’, ‘Walker2d-v5’, or ‘Humanoid-v5’

  • lb (float, default=-1.0) – lower bound of the input space

  • ub (float, default=1.0) – upper bound of the input space

  • num_rollouts (int, default=3) – number of times to run the entire episode for a given policy

  • seed (int | None, default=None) – seed for the environment

Class for computing statistics for a stream of data, here it is used for computing the mean and standard deviation of the observation space of the Mujoco env. This mean and standard deviation is used for normalizing the observation space before computing the next action
