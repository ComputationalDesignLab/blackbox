===============
Basic Tutorials
===============

This section contains simple tutorials highlighting how to initialize and use different problems available in Blackbox. Specifically, each tutorial provides code snippets and step-by-step instructions explaninig how to set up and evaluate a specific problem from Blackbox. These tutorials are designed to help new users quickly get started with Blackbox and understand its core functionalities. After following these tutorials, users should be able to easily set up the problem and evaluate it within higher-level tasks such as surrogate modeling, optimization, etc.
